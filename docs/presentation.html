01Use arrow keys to navigate
The Problem

The catalyst is not a simple Micron headline.

Bear case

Samsung becomes a credible HBM4 supplier sooner than expected, weakening Micron's scarcity premium and future pricing power.

Bull case

More HBM supply helps unlock GPU shipments, accelerates cloud deployment, and benefits equipment, packaging, and downstream AI infrastructure.

I built the system to test how different market participants respond, not to force one static answer.

04Architecture overview
Why Not Default MiroFish?

I kept the useful pattern, but changed the action space.

Default MiroFish

  • Agents post, like, repost, comment, or follow.
  • Useful for social sentiment dynamics.
  • Not enough for investment research.

This implementation

  • Agents revise estimates, change vendor allocation, adjust positions, or flag tool orders.
  • Outputs are schema-validated JSON records.
  • Every action can be traced into the final signal.

This avoids fragile OASIS enum patching while still preserving the swarm architecture.

06Value-chain propagation
Agent Design

Different participants see different parts of the truth.

Market view

Sell-side analysts, buy-side PMs, and traders evaluate valuation, positioning, and risk/reward.

Supply-chain view

Procurement leaders and NVIDIA supply agents see vendor allocation, qualification, and deployment timing.

Company view

Memory executives and equipment reps see capacity plans, pricing strategy, and capex demand.

The simulation deliberately uses information asymmetry. A procurement agent should not reason the same way as a trader.

10Investment synthesis
What I Would Improve Next

The MVP is intentionally scoped, but extensible.

More data

Pull richer FMP fundamentals, estimates, price targets, and holdings into each agent context.

More realism

Run OpenRouter agent generations at scale and compare deterministic vs. LLM decision distributions.

More evaluation

Track forecast outcomes over time and score calibration with Brier scores.

The goal was not to overfit a single answer. It was to build infrastructure that can produce, inspect, and challenge an investment view.

What this demonstrates

  • I converted an ambiguous catalyst into a structured simulation problem.
  • I modified the MiroFish idea into a finance-native decision system.
  • I produced traceable logs, synthesis, forecasts, and a PM-facing memo.
  • I made scoping decisions that are practical for a one-week case study.

The main takeaway: Samsung HBM4 is not just negative for Micron. It is a chain-wide catalyst with different winners, bottlenecks, and risks.
